# Apparatus study prototype

Open `scenes/apparatus_prototype.tscn` in Godot and run it with **F6**. The project startup scene is unchanged.

The prototype compares three support concepts using the existing live vial renderer and drag-and-pour rules:

- **Aperture Ring** — a shared circular instrument with an open central well and stations around the outer ring.
- **Modular Rail** — an adjustable bench rail with independent sliding saddles and retaining arms.
- **Runic Array** — separate pedestals connected to a central rune by faint magical paths.

Use the **4 VIALS**, **6 VIALS**, and **8 VIALS** controls to compare how each concept scales. The 8-vial layouts use two levels so the existing vial size and touch targets remain usable on the portrait screen. Switching either selector reloads the sample puzzle; it does not change the puzzle rules.

This is a visual and interaction study, not a committed final art direction. The apparatus is drawn as a separate layer over the clean greenhouse experiment backdrop. It does not alter the central workshop/home scene, the chapter map, or project startup flow.
