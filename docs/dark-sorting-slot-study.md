# Dark sorting slot study

Open `scenes/dark_sorting_slots_prototype.tscn` in Godot and run it with **F6**. The project startup scene is unchanged.

This test intentionally has no workshop scene, table, apparatus, rack, runes, brackets, or props. It is a dark, low-detail play space with the existing live sorting vials and subtle recessed slot markers only.

Use the layout controls to compare:

- **Line** — one horizontal row for four or six vials; two rows for eight.
- **Arc** — a shallow curved row, or two slightly curved rows for eight.
- **Two Rows** — aligned upper and lower rows for four, six, or eight.

Use **4 Vials**, **6 Vials**, and **8 Vials** to load the corresponding playable sample from the expandable sorting track. Drag and pour, restart, undo, and continue to the next trial as normal.

Changing layout or vial count reloads the current sample puzzle so that each comparison starts from the same initial state. This is a layout test only; it does not replace the chapter environment or alter the main game startup scene.
